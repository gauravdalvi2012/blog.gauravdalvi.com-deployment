# Blog Deployment

Generated deployment output for my personal engineering blog.

The source code for the blog is maintained in a private repository. This public repository contains the generated site published through GitHub Pages.

## Deployment

```text
Private Blog Repository
        │
        ▼
   Production Build
        │
        ▼
Public Deployment Repository
        │
        ▼
   GitHub Pages
        │
        ▼
blog.gauravdalvi.com
````

This repository is deployment infrastructure rather than the source code for the blog.
